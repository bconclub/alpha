# Alphabot — Build Truth

## What Is Alpha
Alpha is a precision momentum-trading bot built by Z at BCON Club. It currently trades **crypto options on Delta Exchange India** (BTC + ETH). The engine still carries code for Bybit, Kraken Futures, and Binance, but the live deployment is **Delta-only options** while those exchanges are disabled. The mission: grow capital through quality trades that beat the fees.

## Trading Logic

### Signal Generation (scalp.py — v6.3)
Every tick, the scalp engine evaluates 12 independent signals. Each signal fires a bull or bear tag.

| # | Signal | Tag | Detection Logic |
|---|--------|-----|----------------|
| 1 | **Momentum** | `MOM:` | 0.12%+ price move in last 60s |
| 2 | **Volume Spike** | `VOL:` | 0.8x+ average volume (pair-adjusted) |
| 3 | **RSI Extreme** | `RSI:` | RSI < 40 (long) or > 60 (short) |
| 4 | **Bollinger Band** | `BB:` | Price outside BB + mean-reversion setup |
| 5 | **5m Momentum** | `MOM5M:` | Sustained 5-candle trend confirmation |
| 6 | **Trend Continuation** | `TCONT:` | New 15-candle extreme + volume |
| 7 | **VWAP Reclaim** | `VWAP:` | Price above VWAP + 9 EMA > 21 EMA ribbon |
| 8 | **BB Squeeze** | `BBSQZ:` | BB inside Keltner Channel → breakout + volume |
| 9 | ~~**Liquidity Sweep**~~ | ~~`LIQSWEEP:`~~ | **DISABLED** — poor performance |
| 10 | **Fair Value Gap** | `FVG:` | 3-candle imbalance gap + price filling |
| 11 | **Volume Divergence** | `VOLDIV:` | Price vs volume trend divergence |
| 12 | **BPRC** | `BPRC:` | Breakout Pullback Reload Continue pattern |

These signals feed into `options_scalp.py`; the option entry does **not** use a raw 4-of-4 gate. Instead it uses the candle-momentum gate described below.

### Options Entry Flow (options_scalp.py)
The only active trading strategy. One position at a time across BTC+ETH.

1. **Regime Gate** — `CHOPPY` blocked; all others allowed
2. **Candle Momentum Gate (Primary)**
   - **ETH**: 4/5 directional candles (0.03% min body), cumulative move ≥ 0.25%, volume ≥ 1.5x avg
   - **BTC**: 5/5 directional candles, cumulative move ≥ 0.40%, volume ≥ 2.0x avg
   - Last 2 candles must both be directional; recent candles must be accelerating
3. **Underlying Move** — price must move ≥ 0.10% in last ~60s
4. **RSI Filter** — calls blocked if RSI > 65; puts blocked if RSI < 35
5. **Confidence Score** — skip if < 0.6; weak-candle penalty (0.5x); BTC gets 0.7x confidence penalty
6. **Expiry** — nearest daily expiry, min 1h away; switch to next day when < 3h remain
7. **Strike Selection** — ETH: ATM only; BTC: 1 OTM first, then ATM fallback
8. **Premium Sweet Spot** — ETH $3–$25, BTC $50–$500. Too cheap = illiquid skip. Expensive = only enter on monster signal.
9. **Limit Entry** — sample ask twice 5s apart; if premium not falling, place limit at first ask and poll 10s for fill
10. **Setup Whitelist** — only `MOMENTUM_BURST` and `BB_SQUEEZE` allowed

### Options Exit System

| Phase | Time | Behavior |
|-------|------|----------|
| **Phase 1** | 0–30s | Only hard SL (-30%) and `OPT_ENTRY_DROP` (-8% in 60s) fire |
| **Phase 2+** | 30s+ | Full exit arsenal active |

#### Ratchet Floor Table (Options)
Locks profit floors as peak premium grows (one-way, never decreases):

| Peak PnL | Floor |
|----------|-------|
| +3% | -2% |
| +5% | 0% (breakeven) |
| +8% | +2% |
| +15% | +5% |
| +25% | +10% |
| +40% | +20% |
| +60% | +35% |

#### Tiered Trailing Stop (Options)
Activates at +10% peak; distance tightens with profit:

| Peak PnL | Trail Distance |
|----------|---------------|
| +10% | 8% |
| +20% | 6% |
| +30% | 5% |
| +50% | 4% |

#### Other Exits
- **TP**: +30% premium gain
- **Pullback**: exit if lost 40% of peak gain (after peak ≥ +8%)
- **Decay**: was +10%+ and faded to +3%
- **Progressive Stale SL**:
  - **ETH**: 5m → tighten to -10%, 8m → -5%, 12m → force `OPT_STALE`
  - **BTC**: 8m → tighten to -15%, 12m → -10%, 18m → force `OPT_STALE`
- **Expiry Guard**: < 30 min always exit; < 2h + PnL < +10% → exit
- **Signal Reversal**: opposite scalp signal fires with 4/4 strength

### Options Sizing
- **Base allocation**: ETH up to 60%, BTC up to 50%
- **Collateral cap**: 40% of balance max per trade
- **Survival mode**: balance < $5 → max 5 contracts
- **Hard cap**: ETH max 40 contracts
- **Confidence multiplier**:
  - 0.9+ → 1.0x base contracts
  - 0.8+ → 0.5x
  - 0.7+ → 0.3x
  - 0.6–0.7 → 0.15x

## Live Position State
The engine writes position state to the DB every ~10 seconds while a position is open:
- **`position_state`**: `'holding'` or `'trailing'`
- **`current_pnl`**: Unrealized P&L %
- **`peak_pnl`**: Highest P&L % reached
- **`current_price`**: Latest premium seen

Dashboard reads via `v_open_positions` view with 3-second live price polling overlay.

## Key Protections
- **Global position lock**: only 1 option position at a time across BTC+ETH
- **No-fill escalation**: consecutive unfilled limits trigger escalating cooldowns (30s → 10min block)
- **Position-gone detection**: verifies exchange positions every ~30s; auto-closes in DB if vanished/expired
- **Orphan protection**: per-exchange reconciliation every 60s
- **Expiry guard**: hard exits before theta decay accelerates
- **Progressive stale SL**: stuck trades get tighter stops instead of arbitrary timeouts
- **Telegram resilience**: Auto-reconnect on failure + health check + clean shutdown
- **WebSocket price feed**: Per-exchange WS for sub-second monitoring
